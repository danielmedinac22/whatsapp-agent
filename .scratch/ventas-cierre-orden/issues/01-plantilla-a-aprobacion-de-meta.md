# 01 — Plantilla de ventas enviada a aprobación de Meta

**What to build:** La plantilla con la que el flujo de confirmación contacta a un cliente que acaba de comprarle al vendedor queda redactada y radicada ante Meta.

No hay código. **Arranca de inmediato y en paralelo con todo lo demás**: es el único elemento del proyecto con tiempo de espera externo, y con el cronograma comprimido tiene que estar aprobada antes de que el handoff se pueda demostrar.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] El texto reconoce que el cliente **acaba de comprar** y se enfoca en verificar los datos de envío, no en preguntar si quiere comprar.
- [ ] Queda claro por qué escribe otro número con otro nombre, para que el cliente no se sorprenda.
- [ ] La plantilla queda radicada ante Meta y el ticket registra la fecha de envío.
- [ ] El ticket registra el resultado de la aprobación cuando llegue, o el motivo de rechazo.
- [ ] Si es rechazada, queda anotada la corrección y la nueva radicación.
