# 03 — Nivel 3: componentes individuales

**What to build:** El detalle final de las piezas que se usan a diario: la tarjeta de producto con su origen, el campo de identificador de anuncio, el marcador de archivo enviable, el estado de reconocimiento dentro de una conversación, y los controles de tomar y devolver el chat.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Un producto conectado a la tienda se distingue de uno nativo **sin leer**.
- [ ] **Registrar un anuncio nuevo se siente de segundos.** Es la interacción más repetida del panel y la que determina cuánto soporte recurrente genera el módulo.
- [ ] Los archivos enviables se distinguen de los no enviables de un vistazo.
- [ ] El estado de reconocimiento —resuelto, ambiguo, escalado— se lee sin abrir la conversación.
- [ ] Tomar el chat comunica inequívocamente que el vendedor quedó pausado.
- [ ] Veredicto por componente, registrado, listo para que la implementación tenga contra qué construir.
